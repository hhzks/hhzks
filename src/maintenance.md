# Maintenance

## The 60-day clock

GitHub **disables scheduled workflows after 60 days of repository inactivity**,
and commits pushed with the default `GITHUB_TOKEN` may not reset that clock.

Check monthly that `daily-lights-out` is still firing, or push a manual commit
now and then. If it has been disabled, GitHub shows a banner on the Actions tab
with a button to re-enable it.

## Cron drift

The schedule is only a request. Actions cron is queued at low priority and
routinely drifts by minutes to hours at peak times, which is why nothing
user-facing promises a specific time of day — the README says "a new puzzle
daily", never "midnight UTC".

`workflow_dispatch` is always available if a day needs to be regenerated by
hand, and takes an optional date:

```
Actions → daily-lights-out → Run workflow → date: 2026-08-04
```

## If a run fails

`verify.py` runs before anything is pushed, so a failure leaves yesterday's
puzzle in place rather than publishing a broken one. Read the failing check in
the run log, then reproduce locally without pushing:

```bash
GITHUB_REPOSITORY=hhzks/hhzks python src/generate.py --date YYYY-MM-DD
GITHUB_REPOSITORY=hhzks/hhzks python src/verify.py   --date YYYY-MM-DD
```

To check a stretch of future dates in one go:

```bash
GITHUB_REPOSITORY=hhzks/hhzks python src/verify.py --days 365
```

## Things that will break it

- **Moving or deleting `src/README.md`.** Every state page and the profile link
  at `src/`, which is only worth opening because GitHub renders that README
  under the file listing. `verify.py` fails the build if it is missing, or if
  the profile stops linking to `src/`. Move it and `render.SOURCE_PATH` has to
  move with it.
- **Deleting a tile image.** `verify.py` checks all three of `on.svg`,
  `off.svg` and `init.svg` exist; the last one is used only by the profile
  board.
- **Removing the `<!-- LIGHTS:START -->` / `<!-- LIGHTS:END -->` markers.** The
  generator rewrites only the region between them and errors if they are absent.
- **Committing the state graph to `main`.** The workflow stages `README.md` and
  `archive` explicitly and never runs `git add -A`. Keep it that way, or the
  repository grows by ~6 MB a day forever.
